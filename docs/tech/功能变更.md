## [CHG-20261024-02] 前端渲染性能与 UI 优化

- **类型**：技术调整
- **日期**：2026-10-24
- **功能说明**：
  - 原行为：虚拟瀑布流每次滚动过滤全部已加载项；分页追加复制整个图片数组；搜索逐字符请求且无取消；灯箱原图预加载无体积上限；侧边栏/卡片/灯箱/回收站等视觉不一致。
